# Citadel status

The working app checks a public page when you type an app or site name (for example Instagram or bbc.com).

Family location uses a Google map on this screen only:
- Show live location reads this device.
- Hide location removes the pin.
- Change location searches a city or address and labels it as a chosen place, not live GPS.

Wipe and the activity log are on one page.

This repository is the earlier client build. The full server-backed app is larger than this snapshot. Do not expect every new check to run from this repo alone until the full tree is published.
